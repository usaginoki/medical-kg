# WorldCuisines

> [!abstract] TL;DR
> WC-KB is a hand-annotated knowledge base of **2,414 culturally specific dishes** chosen from Wikipedia, each with
> coarse/fine food categories, cuisines, the countries and cities/areas that eat it, UN-style sub-regions, a one-
> sentence description (usually naming the main ingredients) and up to 8 CC-licensed images; plus a 401-row table of
> location and cuisine names in 30+ languages. It was built for the WorldCuisines VQA benchmark (NAACL 2025, 1M
> image-question pairs in 30 languages). For the agent it is the broadest open **dish → country/region** map
> (186 countries), with solid coverage of the Middle East (Iran 65, Turkey 69, Saudi Arabia 24, all six GCC
> states ≥10) and South/East/Southeast Asia, but thinner Central Asia (5–10 dishes per country).

## Tables & columns
### `food-kb-v1.1/worldcuisines.csv` (2,414 rows × 39) — WC-KB
Meanings from the paper (§3, "metadata annotation") and dataset card.

| column | type | meaning | example |
|---|---|---|---|
| `food_id` | int | dish id (new in v1.1; used by the VQA `food_id`) | 100 |
| `Name` | str | dish name (English Wikipedia title) | `Kabsa` |
| `Alias` | JSON dict | names in other languages, `{"<code> - <language>": name}` | `{"bg - Bulgarian": "Равон", …}` |
| `Coarse-grained categories` | JSON list | broad food type (244 values) | `["rice"]` |
| `Fine-grained categories` | JSON list | specific type (936 values) | `["mixed rice"]` |
| `Cuisines` | JSON list | cuisine(s) the dish belongs to | `["Saudi Arabian", "Yemeni"]` |
| `Associated Cuisines` | JSON list | other cuisines where it also appears | `["Indonesian","Malaysian","Singaporean"]` |
| `Area` | JSON list | city / sub-national area / region | `["Arabian Peninsula"]`, `["Surabaya", "Malang", …]` |
| `Countries` | JSON list | countries where the dish is commonly consumed/originated; `"Global"` for 80 generic dishes | `["Saudi Arabia", "Yemen"]` |
| `Region1`…`Region5` | str | UN geoscheme sub-region(s) of those countries (inferred from values) | `Western Asia` |
| `Text Description` | str | one-sentence description, usually naming main ingredients | "The dish usually made with rice (usually basmati), meat, Vegetable, and a mixture of spices." |
| `Image1..8 filename` / `name / URL` / `License` | str | up to 8 Wikimedia Commons images with licence | `100_kabsa_1.jpg`, CC-BY-SA 4.0 |

Top coarse categories: bread 339, pastry 294, rice 241, dessert 218, snack 194, meat 190, stew 169, noodle 117, soup 111.

### `location-cuisine-kb/location_and_cuisines.csv` (401 rows × 71)
Parallel names of 401 locations (countries, continents, regions, cities) and their cuisine adjectives in 30+
languages/registers, used to fill `<LOCATION>`/`<CUISINE>` slots in VQA prompts: `key_id` (`location_0`),
`Base Key` (`Afghanistan`), `English_<LOCATION>`, `English_<CUISINE>` (`Afghan`), `English_<CUISINE.w_det>`
(`an Afghan`), then `<Language>_<LOCATION>` / `<Language>_<CUISINE>` with grammatical variants (e.g.
`Czech_<LOCATION.in>`, `Russian_<CUISINE.gen>`) for Indonesian, Chinese, Korean, Japanese, Sundanese, Javanese,
Czech, Spanish, French, **Arabic**, Hindi, Marathi, Bengali, Sinhala, Yoruba, Cantonese, Hokkien, Tagalog, Thai,
**Azerbaijani**, Balinese, Italian, Sardinian, Russian. Useful as a multilingual country/cuisine-name lexicon.

### `vqa-v1.1-subset/hf_prompt/small_eval_task{1,2}/en_small_eval_task{1,2}.jsonl` (300 + 100 rows × 13) — sample only
VQA items: `qa_id`, `lang`, `food_id` (→ KB), `prompt_id`, `prompt_type` (1 no-context, 2 contextualised,
3 adversarial), `image_url`, `image_path`, `task`, `lang_status`, `question`, `options` (5 choices),
`mcq_answer_index`, `answer`. Example: task 2 "Which country made this dish popular?" → `Hungary`. The full VQA is
generated from the KB, so it adds no new dish knowledge.

Sample: `Data/worldcuisines/sample.csv` · full profile: `Data/worldcuisines/schema.md`

## Ingredients, amounts, cooking method
- **Ingredients:** not a structured field; the `Text Description` names main ingredients in prose for most dishes
  ("Mansaf … lamb cooked in a sauce of fermented dried yogurt and served with rice or bulgur"; "Rawon … garlic,
  shallots, star anise, ginger, candlenut, turmeric, red chili, and salt"). `has_ingredients: true` in this weak
  sense — extraction (NER/LLM) is needed.
- **Amounts / cooking method / nutrition:** none (descriptions sometimes say "fried", "simmered").
- **Categories:** coarse/fine dish types give a food-group signal (rice, bread, stew, dessert…).

## Linking to other datasets
- `Name` = English Wikipedia title → Wikidata QID via the Wikipedia API → joins to [[FmLAMA]] (Wikidata dishes with
  `hasParts` ingredients), which fills WorldCuisines' missing ingredient field.
- Dish names can be fuzzy-matched to [[World Wide Dishes]] (the WWD paper compares the two, App. D.2).
- `location_and_cuisines.csv` gives multilingual country/cuisine names for matching labels in other datasets
  (e.g. Arabic names for [[ArabCulture]] or Azerbaijani for [[BLEnD]]).

## Versions
- **food-kb v1** (`worldcuisines/food-kb`, Oct 2024; parquet + CSV + images) → **food-kb-v1.1** (Apr 2025): adds the
  `food_id` column, fixes 2 dish names and 3 image filenames, re-serialises `Alias`; same 2,414 dishes (checked by
  diffing both CSVs).
- **vqa** v1 (with images) → **vqa-v1.1** (Nov 2025): images removed, text unchanged; `vqa-v1.1-reversed` also exists.
- `worldcuisines/prompt-kb` holds the 90 multilingual prompt templates (not downloaded).

## Caveats
- Dish selection is Wikipedia-driven (needs its own Wikipedia page, "culturally specific" only), so home cooking and
  low-internet regions are under-represented; the WWD paper shows its coverage tracks internet access.
- Countries list "where commonly consumed", so pan-regional dishes inflate small-country counts.
- No structured ingredients; images are Wikimedia with mixed licences.
